# BreePhone

BreePhone 是一款面向 macOS 的原生 SIP 软电话。它没有 Electron，也不要求额外安装运行时，下载 DMG、拖进“应用程序”就可以使用。

目前支持 macOS 13（Ventura）及以上版本，提供 Apple Silicon 架构构建。

## 功能

### 账号与注册

- 支持多个 SIP 账号同时在线，可以拖动排序、单独启用或停用，并指定默认呼出账号。
- 支持 UDP、TCP 和 TLS 传输；注册间隔、STUN、TURN、ICE 等参数按账号配置。
- 密码和 TURN 凭据存放在 macOS 钥匙串中，不写入数据库，也不会出现在日志里。
- 切换 Wi-Fi、网线、热点或 VPN 后，通话不断线，并自动重新探测网络并注册，不需要重启应用。

### 通话

- 拨号盘、联系人、通话记录和独立的通话中界面。
- 支持保持 / 恢复、DTMF、自动接听和来电等待。
- “静音”只关闭麦克风方向；“关扬声器”只关闭播放方向，两者相互独立。
- 通话过程中可以切换输入和输出设备，设置立即生效。
- 菜单栏常驻显示注册状态和通话时长，不通话时可以收起主窗口。

### 数据与迁移

- 可以把账号、联系人、通话记录和应用设置导出成一个备份文件。
- 导入前会显示摘要，可以选择整体覆盖或与现有数据合并。
- 日志写入本地文件并自动轮转，不写入 Console.app 的统一日志库。

## 排障

SIP 电话最难判断的通常是两类问题：请求没有到达服务器，或者电话接通后媒体没有建立。BreePhone 把常用的检查工具放进了界面。

在“设置 → 网络相关”中执行一次检查，应用会依次确认：

1. 本机 SIP 监听是否正常；
2. SIP 服务器域名解析到了哪个地址；
3. 拨号和语音使用的本机网络接口；
4. STUN 获取到的对外地址，以及端口是否被 NAT 改写。

检查结果会附带下一步建议。例如发现路由器改写了端口时，应用会说明为什么不向外通告该地址。

### 网络状态胶囊

顶栏的网络胶囊会持续显示当前网络类型和质量。展开后可以看到往返时延、波动、丢包、链路速率、出口网卡，以及是否检测到 VPN 或代理。每个指标都提供计算口径说明，便于判断“慢”究竟发生在哪里。

### SIP 信令详情

在通话记录详情中可以查看完整的 SIP 时序。报文按实际收发方向排列，包含 INVITE、100/180、200 OK、ACK、BYE 等关键节点，并标记挂机方、结束状态和结束原因。

常见的判断方式：

- 呼出后没有任何回包：请求可能没有发出，或被本地网络拦截；
- 只收到 `100 Trying`：INVITE 可能被服务器或中间设备丢弃；
- 收到 `200 OK` 却没有 ACK：通常要继续检查媒体地址或路由；
- SIP 正常但没有声音：结合通话界面的 RTP 收发电平和日志中的 `[RTP TX]` / `[RTP RX]` 判断是哪一侧没有媒体流。

## 安装与迁移

### 安装

1. 下载对应版本的 DMG。
2. 双击挂载磁盘映像，将 BreePhone 拖入“应用程序”。
3. 首次启动时按上面的方式通过 Gatekeeper 确认。

### 迁移到另一台 Mac

在“设置 → 数据”中导出备份文件，在新机器安装 BreePhone 后选择“导入数据”。导入前会先展示账号数量、联系人和通话记录摘要，再由你选择覆盖或合并。

## 常见问题

### 通话接通后听不到声音

先运行网络自检。如果 STUN 无响应，先换到手机热点等网络确认问题是否来自当前网络；如果拿到的是内网地址，能否通话取决于 SIP 服务器和对端的 NAT 配置。四项检查都正常时，再看 RTP 收发状态：只发送不接收通常意味着对端媒体没有抵达本机。

SIP 监听端口不是 5060 并不代表异常。应用刻意使用随机高位端口，以减少部分网络设备对 SIP / SDP 的错误改写。

### 开启 VPN 后注册失败

应用会在网络变化后自动重探和重试注册。如果仍未恢复，可以在“设置 → 账号”中手动重新注册，并检查 VPN 是否阻止了 SIP 或 STUN 流量。

### 支持哪些编码

默认协商顺序为：`opus/48000/2`、`G722/16000/1`、`PCMU`、`PCMA`、`L16/44100/2` 和 `L16/44100/1`。可以在账号设置中调整启用状态和顺序。

### 有 Intel、Windows 或 Linux 版本吗

目前只有 Apple Silicon 版，暂未提供 Intel、Windows 或 Linux 构建。

### 可以从脚本发起呼叫吗

可以。应用注册了 `bree://` URL Scheme：

```text
bree://call/1002
bree:1002
bree://hangup
```

## 数据位置

| 内容 | 位置 |
| --- | --- |
| 账号、联系人、通话记录 | `~/Library/Application Support/BreePhone/breephone.sqlite` |
| 日志 | `~/Library/Application Support/BreePhone/breephone.log` |
| 账号密码、TURN 密码 | macOS 钥匙串 |
| 其它界面设置 | `UserDefaults` |
